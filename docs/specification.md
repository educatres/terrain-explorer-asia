# 亞洲地形與生態互動式教材規格書

## 專案目標

建立可部署在 GitHub Pages 的亞洲互動式地理教材。學生以亞洲為中心的地圖探索山脈、水文、特殊地形、國家公園及代表性動植物，理解地理環境與生態分布的空間關係。

## 學習目標

1. 辨識亞洲主要山脈、高原、沙漠、河流與湖泊。
2. 說明板塊運動、河流、冰河、風化與喀斯特作用如何塑造地形。
3. 比較東亞、東南亞、南亞、中亞、西亞與北亞的自然環境。
4. 連結棲地條件、物種適應與保育議題。
5. 練習使用有來源的地理資訊。

## 地圖與互動

- 使用 Leaflet 與 Esri World Imagery。
- 初始畫面涵蓋亞洲，中心約位於亞洲中部；主要瀏覽邊界限制在南緯 12 度至北緯 80 度、東經 25–180 度附近。
- 提供山脈、河流、湖泊、特殊地形、國家公園、動物與植物七類篩選。
- 地形標記保留永久名稱；物種以圖標表示，避免總覽時過度擁擠。
- 支援名稱搜尋、清單選取、自動導覽、觀察任務與隨機測驗。

## 資料結構

```text
terrain-explorer-asia/
├── index.html
├── css/style.css
├── js/app.js
├── data/
│   ├── places.json
│   ├── species.json
│   ├── quizzes.json
│   └── photos.json
├── geojson/
│   ├── mountains.geojson
│   ├── rivers.geojson
│   └── lakes.geojson
└── docs/
```

景點資料至少包含識別碼、中英文名稱、類別、國家或地區、座標、簡介、形成原因、觀察重點、思考問題與來源。物種資料另包含學名、棲地、生態特徵及保育資訊。

## 內容與品質要求

- 所有執行階段的標題、標記、導覽路線、測驗與 GeoJSON 均限亞洲主題。
- 座標採 Leaflet 的 `[緯度, 經度]`，GeoJSON 採 `[經度, 緯度]`。
- 概略線面必須標明教學用途，不可當成精確邊界。
- 外部來源使用 HTTPS，開新分頁時加上 `rel="noopener"`。
- 桌面與行動版皆需可操作，互動元件具有文字或無障礙標籤。

## 驗收

1. 頁面啟動後以亞洲為中心，所有景點與物種標記均屬亞洲主題。
2. 七類篩選、搜尋、導覽、資訊卡與測驗均可操作。
3. 所有 JSON 與 GeoJSON 可解析，導覽識別碼皆存在。
4. 專案文字與資料檔不殘留其他洲別的舊教材內容。
