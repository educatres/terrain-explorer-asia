# 教師使用指南

## 建議教學流程（45–50 分鐘）

1. **亞洲總覽（8 分鐘）**：從衛星圖辨識亞洲的高山、高原、內陸沙漠與季風區。
2. **山脈與河流（10 分鐘）**：同時開啟山脈、河流圖層，討論青藏高原與亞洲大河源區的關係。
3. **特殊地形（12 分鐘）**：比較戈壁沙漠、張家界峰林、下龍灣喀斯特與青藏高原。
4. **國家公園案例（10 分鐘）**：每組選一座亞洲國家公園，閱讀資訊卡並開啟主要來源。
5. **隨機挑戰（5–10 分鐘）**：全班共同作答或分組競賽。

## 課堂任務範例

- 比較喜馬拉雅山脈與烏拉山脈的高度和地質年代。
- 找出三條源自亞洲高地的大河，觀察它們的流向。
- 說明裏海與死海鹽度較高的共同原因。
- 比較戈壁沙漠與婆羅洲熱帶雨林的水分條件。
- 選擇一種亞洲特有或代表性物種，說明其棲地需求。

## 資訊素養提醒

請學生區分「地圖上的概略示意」與「原始科學資料」，並要求報告保留來源名稱與連結。物種標記是代表性位置，不是完整分布圖。
